Проекты в ArchMap изолированы: у каждого свои объекты, связи и документация. Проект виден либо его участникам, либо — если владелец включил «Виден всем пользователям» — всем, кто вошёл в сервис. Во втором случае не-участники могут только читать.

<!--@include: ../_shared/project-roles.md-->

## Если проекта не видно

Проект, в который вас не добавили и который не открыт для всех, не показывается в списке «Проекты» и недоступен по прямой ссылке. Попросите владельца проекта добавить вас участником — ему нужна ваша учётная запись в сервисе. Учётные записи заводит администратор, см. [Пользователи и роли](../admin/users.md).
