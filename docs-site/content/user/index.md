short: Пользователь

description: Как читать схемы, перемещаться по уровням, открывать страницы объектов и находить нужное.
---

Это руководство для тех, кто открывает ArchMap, чтобы разобраться в системе: разработчиков, аналитиков, тестировщиков, новых участников команды. Для чтения не нужны особые права — достаточно, чтобы проект был виден вам (см. [Доступ к проектам](access.md)).

Если вы будете строить и править схемы, после этого руководства переходите к [Руководству архитектора](../architect/index.md).
