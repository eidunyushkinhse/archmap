Docker Compose поднимает ArchMap вместе с PostgreSQL на одной машине. Подходит для команды до нескольких десятков человек и для знакомства с сервисом.

## Что нужно

- Linux-сервер или рабочая машина с Docker и Compose v2.
- Интернет на время сборки: образ собирается из исходников, Node.js и Python ставятся внутри сборки.
- 2 ГБ памяти и 5 ГБ на диске для базы и образов.

## Запуск

```bash
git clone https://github.com/eidunyushkinhse/archmap.git
cd archmap
docker compose up -d
```

Первая сборка занимает несколько минут. Когда она закончится, интерфейс отвечает на `http://localhost:8080`. Compose сам ждёт готовности базы, применяет миграции и запускает приложение.

## Первый администратор

Регистрации по умолчанию нет: первую учётную запись создаёт команда внутри контейнера.

```bash
docker compose exec archmap archmap-admin create-admin admin
```

Команда спросит пароль и создаст пользователя `admin` с правами администратора. Дальше учётные записи заводятся в интерфейсе, см. [Пользователи и роли](users.md).

::: warning Ключ подписи входа
При первом старте контейнер создаёт ключ подписи сессий и кладёт его в том `archmap_data`. Не удаляйте том при обновлении — иначе всем придётся войти заново. Свой ключ можно задать переменной `SECRET_KEY` сервиса `archmap`.
:::

## Настройки

Порт и пароль базы задаются в файле `.env` рядом с `compose.yaml`:

```ini
ARCHMAP_PORT=8080
POSTGRES_PASSWORD=замените-до-первого-запуска
```

Пароль базы PostgreSQL запоминает при создании тома, поэтому задайте его до первого запуска.

## Обновление

```bash
git pull
docker compose up -d --build
```

Миграции применяются при старте контейнера. Если новая версия не поднялась, вернитесь к прежнему коммиту и повторите запуск: база обратно не мигрирует, поэтому перед обновлением снимите копию.

## Резервные копии

База живёт в томе `archmap_db`. Для копии достаточно `pg_dump` из контейнера базы:

```bash
docker compose exec db pg_dump -U archmap -Fc archmap > archmap-$(date +%F).dump
```

::: note
Контейнер отдаёт HTTP без TLS. Чтобы открыть ArchMap коллегам по сети, поставьте перед ним обратный прокси с TLS и задайте сервису `archmap` переменную `TRUST_FORWARDED_FOR: "true"` — иначе лимит попыток входа посчитает всех пользователей одним адресом прокси.
:::
