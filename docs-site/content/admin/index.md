Администратор ставит ArchMap, заводит учётные записи и следит за сервисом. Ему не обязательно разбираться в схемах, но полезно знать, как устроен [доступ к проектам](../user/access.md), чтобы правильно выдавать роли.

ArchMap поставляется тремя способами: Docker Compose для одной машины, Helm-чарт для Kubernetes и установка на сервер со службой systemd и nginx. В этом руководстве пока описан первый; остальные — в файле DEPLOY.md репозитория.
