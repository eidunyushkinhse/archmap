В ArchMap два уровня ролей. Общая роль говорит, что человек может делать в сервисе вообще; роль в проекте — что он может в конкретном проекте.

## Учётные записи

Пользователей заводит администратор на экране «Пользователи»: имя входа, пароль и общая роль. Самостоятельной регистрации нет, пока не включена настройка `ALLOW_SIGNUP`. Пользователь может сменить свой пароль в меню профиля; администратор — сбросить чужой.

## Общие роли

| Роль | Что даёт |
| --- | --- |
| **Администратор** | Управление пользователями и всеми проектами. Первого администратора создаёт команда `archmap-admin create-admin`, следующих назначает любой администратор. |
| **Архитектор** | Может создавать проекты и становится их владельцем. |
| **Пользователь** | Не создаёт проекты; работает в тех, куда его добавили, и в открытых для всех. |

<!--@include: ../_shared/project-roles.md-->

::: note
Общая роль не даёт прав внутри чужого проекта: архитектор без участия в проекте видит его, только если он открыт для всех, — и только как читатель.
:::
