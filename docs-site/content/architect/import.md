Схему редко рисуют с нуля. Обычно её собирают из описаний: YAML в формате экспорта ArchMap, архива другого проекта или результатов работы ИИ-агента над репозиторием.

## Формат YAML {#yaml}

Это тот же формат, что отдаёт «Экспорт». Минимальный проект — список объектов с вложенностью и список связей:

```yaml
nodes:
  - name: Витрина
    shape: service
    technology: React
  - name: Сервис заказов
    shape: service
    technology: Python
    children:
      - name: API заказов
        shape: service
      - name: База заказов
        shape: database
        technology: PostgreSQL
edges:
  - from: Витрина
    to: Сервис заказов / API заказов
    label: оформление заказа
    technology: HTTPS
```

Путь к вложенному объекту записывается через « / ».

## Единый импорт {#unified}

Окно «Импорт» принимает несколько входов сразу: YAML-файлы, архивы `.zip` и вставленный текст. Перед применением ArchMap показывает превью — что добавится, что изменится, что совпало с уже существующим — и задаёт вопросы там, где не смог решить сам.

1. Откройте проект и нажмите «Импорт».
2. Добавьте файлы или вставьте YAML.
3. Проверьте превью. Объекты с одинаковыми именами склеиваются; спорные случаи помечены вопросами.
4. Нажмите «Применить».

::: tip
Импорт можно запускать в уже наполненный проект: существующие объекты не дублируются, а дополняются. Ручные правки — расстановка и документация — сохраняются.
:::

## Из репозитория {#repo}

ArchMap не ходит в репозиторий сам. Вместо этого он выдаёт промпт для вашего ИИ-агента (Claude Code, Qwen Code и подобных): агент изучает код и возвращает YAML, который вы импортируете обычным путём. Так же устроены разведка точек входа и документация логики.

Чтобы обновления из кода не ломали ручные правки, у объекта есть **якорь** — путь в репозитории или имя зависимости. При повторном импорте объект узнаётся по якорю, даже если его переименовали.

## Факты из кода {#facts}

Структура базы, каналы брокера и параметры конфигурации ввозятся отдельно — по семьям фактов, каждая со своим промптом. Как они показываются читателю, описано в разделе [Факты](../user/node-page.md#facts) руководства пользователя.

::: details Что делать, если импорт нашёл дубли
Если в превью два объекта помечены как «похоже на …», проверьте их якоря. Объекты с разными якорями считаются разными даже при одинаковых именах. Задайте якорь у существующего объекта и повторите импорт.
:::
