# Материалы разведки эпика «Элемент C4: система · контейнер · компонент»

Собраны 2026-10-28 до начала реализации. Сводный план с решениями владельца, реестром мест,
подводными камнями и фазами — `docs/plan-c4-elements.md`. Здесь лежат исходники, по которым
он собран. Все ссылки путь:строка в отчётах даны по состоянию main 6869acc3 и со временем
устареют; при реализации сверять по месту.

| Файл | Что это |
|---|---|
| `concept.md` | Концепция эпика, выданная всем разведчикам одним текстом: как устроено сегодня, что предлагается, следствия по семьям, открытые вопросы |
| `scout-backend-core.md` | Ядро модели и API: хранение роли, контракт, правки узла, копия и снимки, YAML, мердж, догрузка, синк, промпт ввоза, тесты (13 вопросов владельцу, фазы Ф1–Ф6) |
| `scout-backend-facts.md` | Семьи фактов (конфигурация, спека, схемы и разведка, таблицы и каналы), размещение, алерты AL*, промпты фактов; формула «ближайший контейнер» и ~25 мест её вызова |
| `scout-canvas.md` | Холст и нормативные спеки: где закодировано «узел с детьми = рамка», три копии стиля рамки, варианты плитки и шапки, кэш роутера и полигон, холст «Развёртывание», лендинг |
| `scout-ui.md` | Страницы, панели и тексты фронта: 253 строки с маркерами, ~55 к правке по смыслу, точки решения «контейнер» (~25), тур и демо, типы, тесты, образцы контролов |
| `scout-mcp.md` | MCP-сервер и всё, что читает агент: описания инструментов, рендер, README, промпты (с предлагаемыми формулировками), синк через MCP, расхождение версий |
| `scout-docs.md` | spec.md, CLAUDE.md, docs/specs, планы и ТЗ, сайт документации (23 страницы, снимки), лендинг (тексты и кадры), демо и тур, скрипты и гейты CI; таблица отменяемых решений |
| `scout-data.md` | Замеры dev-базы только чтением: 58 проектов, 2410 узлов, 273 с детьми; факты на родителях, эвристики роли по источникам, связи в родителей, глубина, размещение, выводы для миграции |
| `design-lexicon.md` | Лексикон (таблица терминов RU/EN, спорные слова), тексты объяснений для доки, «?» и промптов, UI-спецификация по экранам с макетами, холст, миграция, риски путаницы, критика прототипов |
| `prototype-logic.html` | Интерактивный прототип логики (три режима, переключатели, пересчёт алертов). Словарь прототипа («коробка», «модуль») устарел, см. критику в `design-lexicon.md` §7 |
| `prototype-canvas.html` | Прототип холста: четыре сцены, термины, контрол инспектора. Шапка и заливка рамки контейнера, уменьшенная плитка компонента и чипы дерева дизайн-ревью отклонены |

Отчёты писались независимо и местами расходятся (имя поля, пикер связи в контейнер, статус
страницы контейнера). Расхождения сведены в разделе «Решения владельца» плана, там же даны
рекомендации.
