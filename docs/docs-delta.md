# Изменения продукта относительно docs.archmap.tech

Живой список того, что появилось или изменилось в ArchMap после написания
пользовательской документации (github.com/eidunyushkinhse/archmap-docs, русская версия
принята 2026-10-18). По нему обновляют сайт: пункт снимается, когда страница сайта
обновлена. Ведётся с 2026-10-23 по просьбе владельца; пополнять в том же коммите, что и
фича. У каждого раздела — какие страницы сайта затронуты (`user/…`, `architect/…`,
`admin/…` — папки `content/` репозитория документации).

Сборщик 0.8.0 (2026-11-11, часть 6). Страницы `architect/scan.md`, `architect/config.md` и
`architect/channels.md` ждут дополнения:

- параметры общего кода (файл вне каталогов кода всех контейнеров или в каталоге контейнеров
  другого языка) сборщик больше не прячет в подсказки: они лежат готовыми файлами
  `facts/shared/<каталог>.config.yaml` с пустой первой строкой `# archmap-node:`; чтобы ввезти
  такой файл, в первую строку вписывают адрес контейнера, который выполняет этот код, и подают
  файл как остальные. Без адреса ArchMap файл отвергает (`architect/scan.md`, `architect/config.md`);
- каналы Redis pub/sub из кода (Python, Node.js, Ruby, Go) попадают в `facts/<redis>.channels.yaml`
  с видом `channel`; Redis, в который публикует код контейнера, становится брокером, а брокер
  Redis, который служит и кэшем (Rails, Django, Laravel, пакет кэша Node.js), получает роль
