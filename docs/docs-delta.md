# Изменения продукта относительно docs.archmap.tech

Живой список того, что появилось или изменилось в ArchMap после написания
пользовательской документации (github.com/eidunyushkinhse/archmap-docs, русская версия
принята 2026-10-18). По нему обновляют сайт: пункт снимается, когда страница сайта
обновлена. Ведётся с 2026-10-23 по просьбе владельца; пополнять в том же коммите, что и
фича. У каждого раздела — какие страницы сайта затронуты (`user/…`, `architect/…`,
`admin/…` — папки `content/` репозитория документации).

## Снято 2026-10-28

MCP: файл с машины агента без перепечатки (2026-10-28, MCP 0.10.0, docs/plan-mcp-upload.md) —
инструмент `archmap_upload_url` (одноразовая ссылка на 10 минут, до 2 МБ, `curl -T` без токена
в команде), `{name, upload_id}` в `files` любого инструмента, эхо размера и sha256 у каждого
инструмента с файлами. На сайт НЕ переносится (решение владельца 2026-10-28): загрузку агент
делает сам по описаниям инструментов, а механика для того, кто подключает агента, описана в
`mcp/README.md` репозитория ArchMap. Раздел «Передать агенту большой файл», добавленный
коммитом 981a493 (archmap-docs), снят коммитом db4ed2e.

Синхронизация: каналы связей (починка по репорту с рабочего проекта, 2026-10-28) —
канал брокера и тип канала у связей переносятся из YAML (раньше терялись), связи одной пары
различаются каналом, у живой связи без канала он заполняется из YAML; в плане окна
**Обновить из репозитория** появилась группа **Изменённые связи**. На сайт перенесено
коммитом документации c0d905f (archmap-docs): список групп плана на `architect/sync.md`
называет новую группу. Аргумент `channel` у `archmap_update_edge` страницу MCP не меняет
(аргументы инструментов она не перечисляет).

## Снято 2026-11-04 (сборщик фактов)

Сайт обновлён и выложен 2026-11-04: archmap-docs 702267d (страница «Собрать схему и факты из
репозитория без агента», заметки на семи страницах) и правка агентского пути того же дня
(факты из файлов сборщика в «Документировать систему» и «Импортировать схему», заголовок
раздела MCP, порядок страниц). Ниже то, что было в дельте.

Эпик docs/tasks/fact-collector.md, нулевая версия `archmap-scan.pyz` 0.1.0. Новый путь без агента:

- скачать файл без входа: `<адрес ArchMap>/api/v1/scan/archmap-scan.pyz` (версия и sha256 —
  `GET /api/v1/scan`);
- запустить в репозитории `python3 archmap-scan.pyz [ПУТЬ] [--system ИМЯ] [--out КАТАЛОГ]`
  (Python 3.10 и новее, ставить ничего не нужно) и прочитать `summary.txt`: что найдено, что не
  покрыто, как импортировать;
- импортировать `schema.yaml` в окне «Новый проект» способом «Импорт» (в открытый проект через
  «Обновить из кода»), файлы `facts/` окнами «+ Таблица», «+ Параметр», «+ Канал» способом «Через
  ИИ-агента». Описаний и связей сверх манифестов в схеме нет, их дописывают агент или человек.

Страницы сайта: `architect/import-agent.md` (путь без агента рядом с агентским) или новая страница
о сборщике; `architect/create-project.md` (способ «Импорт» принимает `schema.yaml` сборщика);
`architect/db.md`, `architect/config.md`, `architect/channels.md` (файлы фактов сборщика). Не
трогать `user/agent-setup.md` и `architect/mcp.md`: агент в нулевой версии сборщик сам не
запускает, интеграция с агентом — фаза 3.

Фаза 3 (2026-11-04, агент). Страницы написаны в archmap-docs на ветке feat/fact-collector
(702267d), выкладка после слияния эпика:

- агент сам запускает сборщик первым шагом промпта ввоза и обновления из кода: инструментом
  `archmap_scan` локального MCP-сервера или командами `curl` и `python3` из промпта (адрес файла
  на этом сервере называет промпт). Делать ничего не нужно; если адрес ArchMap агенту
  недоступен, файл кладут в корень репозитория руками и пишут об этом в поле «Подсказки
  агенту» (`architect/import-agent.md`);
- локальный MCP-сервер 0.14.0: инструмент `archmap_scan`, всего 42 (`architect/mcp.md`);
- окно «Новый проект» на способе «Импорт» и окно «Обновить из кода» показывают ссылку на файл
  сборщика с его версией (на установке без файла ссылки нет);
- превью ввоза и план обновления из кода помечают файл сборщика серой строкой «Собрано
  сборщиком фактов ArchMap <версия> по коммиту … репозитория …» (`architect/export-import.md`,
  `architect/sync.md`); то же в отчётах файлов фактов;
- новая страница `architect/scan.md` «Собрать схему и факты из репозитория без агента»
  (скачать, запустить, импортировать схему, добавить факты); заметки о файлах сборщика в
  `architect/db.md`, `architect/config.md`, `architect/channels.md`.
