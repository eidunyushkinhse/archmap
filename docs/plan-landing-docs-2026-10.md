## Ф0. Предпосылки (без них нечего снимать)

1. **Выкатить main на демо-стенд.** `deploy/build-bundle.sh` → scp → `install.sh` по рецепту
   памяти `public-stand`. Миграции: `node_versions`, `deployment_sites`/`deployment_instances`,
   перенос данных размещения, статус страницы — установщик снимает копию базы сам. Смоук:
   гость → «Ярмарка» → переключатель режимов из трёх вкладок, страница объекта с пилюлей
   статуса и строкой «Размещение», ⋯ → «Версии документации».
2. **Посеять размещение в эталон «Ярмарка v2»** (сейчас в проекте 0 площадок — холст
   «Развёртывание» пуст, снимать нечего). Предложение топологии (нейтральные имена, в пределах
   демо-лимита 20 площадок):
   - «Облако» (облако) ⊃ «Кластер prod» (Kubernetes): API Gateway, Order API, Search API,
     Индексатор товаров, Сервис оплаты, воркеры уведомлений;
   - «Облако» ⊃ «Кластер резерв» (Kubernetes): второй экземпляр Order API и API Gateway —
     на схеме появятся пометки «1/2» и стрелки к ближайшим экземплярам;
   - «Облако» ⊃ «Управляемая PostgreSQL» (другое): БД заказов, БД каталога;
   - «Облако» ⊃ «ВМ брокера» (виртуальная машина): Kafka; «ВМ поиска»: Elasticsearch;
   - «Серверная офиса» (физический сервер): SMS-рассыльщик (выводится) — старый путь ещё
     крутится на железе;
   - один-два объекта оставить без размещения — видна группа «Размещение не указано»;
   - «Сервис рекомендаций» (проектируется) — без размещения.
   Точные имена объектов сверить с эталоном при посеве. Размещать окном «Размещение» или
   MCP `archmap_update_node.sites` (площадки создаются только в интерфейсе).
3. **Обновить демо-пакет** из эталона: `scripts/refresh-demo-template.py` → пакет
   `backend/app/template_packages/demo-marketplace` получит раздел `deployment` и `sites`
   объектов → коммит в main → повторная выкатка на демо (п. 1 можно сделать сразу после этого
   пункта, одной выкаткой).
4. **Статусы и версии в эталоне**: две-три страницы перевести в «согласовано» (контейнер
   покажет «· N из M»), зафиксировать одну версию корня и одну версию объекта с правкой после
   неё — для кадров панели версий. Версии в архив и демо-пакет не едут: на стенде
   документации и на копии для съёмки сделать то же руками перед кадром.
5. **Стенд скриншотов документации**: поднять `./dev.sh` на базе `archmap_docs`
   (миграции накатятся), пересобрать архив `yarmarka.zip` из обновлённого эталона и
   пересеять (`seed.sh`); корень «Ярмарки» там расставлен руками — проверить, что
   пересев не сломал раскладку (память `docs-site-epic`, README стенда).
