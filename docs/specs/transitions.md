# Анимации переходов — спецификация поведения

Нормативный реестр инвариантов СИСТЕМЫ плавных переходов уровневой схемы:
тихое окно пересчётов, фазы режиссуры, Web Worker конвейера, каскад drawIn,
отмены. Формат — [README.md](README.md). Отдельные эффекты закреплены в
соседних спеках: спавн/сворачивание — [container.md](container.md) C29–C31,
drawIn после жеста — [edge.md](edge.md) E64–E66, переезды узла —
[node.md](node.md) N30; здесь — системный слой.

Код: `graph/interaction/{layoutAnimation,useLayoutAnimation}.ts` (планировщики /
оркестратор), `components/LevelGraph.tsx` (тихое окно, gate, computeNow),
`LevelGraph.css` (транзишены/keyframes), `graph/edges.tsx` (drawIn-рендер),
`graph/EdgeJumpContext.tsx` (заморозка мостиков),
`graph/layout/{pipeline.worker,pipelineClient,layoutSig}.ts`,
`graph/reconcileRf.ts`, полигон `scripts/dump-levels.mjs`.

## 1. Архитектура

- **AN1.** Единственная точка записи раскладки в RF-стейт — apply оркестратора:
  сборка → реконсиляция → applyLayout; без свежего интента применение
  прозрачно, с интентом — режиссура. [код]
- **AN2.** Роли жёстко разделены: планировщики — чистые функции
  «prev + next → план первого кадра + что спрятать»; хук — таймеры, маски,
  эпохи; LevelGraph владеет тихим окном через интерфейс gate
  `{hold, flush, release, reset}`. [код]
- **AN3.** Интент `{kind: expand|collapse, id, ts}` ставится обработчиком ДО
  коммита expanded; прогоном, где план невозможен (null), НЕ потребляется —
  ждёт подходящего и протухает за `INTENT_TTL_MS = 15000`.
  [null-планы — тест: layoutAnimation.test.ts; TTL — код]
- **AN4.** Латентность старта раскрытия локала срезана батчем: expanded
  включается ОДНИМ setState с приходом детей — промежуточного прогона
  «expanded есть, детей нет» не существует. [код]

## 2. Фазы раскрытия

- **AN5.** Последовательность expand: hold тихого окна → пауза мостиков →
  маска (рамки-новички + задетые рёбра) → первый кадр (стопка) → фиксация
  2×rAF → отпуск на финальные позиции → move 420мс → «мёртвая зона»: flush
  (досчёт отложенного + ожидание применения) → unmask (фейд рамок 200мс +
  drawIn рёбер) → endDraw по последней волне. [планы — тест:
  layoutAnimation.test.ts; секвенция — код + полигон]
- **AN6.** Первый кадр: НОВЫЕ узлы — стопкой в центре прежнего свёрнутого узла
  (относительные координаты через цепочку родителей next); уже жившие узлы
  получают финальные позиции сразу — их довозит CSS-transition параллельно;
  «новизна» рамки — смена ТИПА под тем же id; раскрытие без новых узлов →
  план null. [тест: layoutAnimation.test.ts]
- **AN7.** Прячутся на разъезд: рамки-новички (opacity 0) и рёбра, у которых
  конец новый или сместился >0.5px ПО АБСОЛЮТУ, плюс все новые пучки.
  [тест: layoutAnimation.test.ts]
- **AN8.** Нативные рамки breadcrumb едут теми же 420мс: bbox пересчитывается
  каждый рендер, а транзишен left/top/width/height под классом анимации
  превращает скачок в глиссаду. [глаза]

## 3. Фазы сворачивания

- **AN9.** Последовательность collapse: снимок id рёбер ДО фазы 1 → pending =
  свежая раскладка → фаза 1 НА ТЕКУЩЕМ СНИМКЕ: потомки (включая глубоких, по
  цепочке parentId старого снимка) съезжаются в центр будущего узла, рамки
  поддерева гаснут, соседи довозятся в СТАРОЙ системе координат → 420мс
  (laterFromFrame) → мёртвая зона: flush → своп на САМОЕ СВЕЖЕЕ из pending
  (батчем со снятием паузы мостиков) → drawIn для скрытых в фазе 1 и новых
  пучков → endDraw. [план фазы 1 — тест: layoutAnimation.test.ts;
  секвенция — код]
- **AN10.** Пока идёт фаза 1, каждый новый apply просто перезаписывает pending
  — свопается только последний результат. [код]

## 4. Тихое окно и «мёртвая зона»

- **AN11.** На окно откладывается ВЕСЬ прогон конвейера (проекция → ELK →
  кольца → инварианты → роутер → плашки): эффект раскладки при hold лишь
  помечает dirty и выходит; сигналы — синхронные ref, не state. [код]
- **AN12.** «Мёртвая зона» — узлы доехали, задетые рёбра ещё скрыты, рамки не
  проявлены: тяжёлый досчёт и тотальный apply падают в невидимый интервал.
  [код]
- **AN13.** «Unmask ждёт применения»: flush при dirty досчитывает и, если
  прогон применился, ждёт его applyLayout (промис резолвится в сборщике);
  прогоны со статусом skipped/stale не ждутся — применение придёт от
  победителя; без dirty flush — мгновенный no-op. [код]
- **AN14.** release (конец окна) снимает hold и досчитывает накопленное В
  ФОНЕ; reset (смена уровня) — ВЫБРАСЫВАЕТ dirty (уровень пересчитает свой
  эффект). endDraw — конечная точка обеих режиссур; если drawIn не стартовал,
  окно закрывает unmask/своп. [код]
- **AN15.** Пересчёт, применившийся ПОСРЕДИ окна (стартовал до hold), маску не
  разоблачает: рамки и рёбра из масок повторно прячутся, рёбра фазы отрисовки
  повторно помечаются drawIn. [код]
- **AN16.** Пауза реестра мостиков входит в окно: заморозка ставится батчем с
  планом, снимается батчем с unmask/свопом — пересборка реестра проходит до
  первого кадра drawIn (§11). [код]
- **AN17.** DOM-замеры, пришедшие в окно, счёт не запускают: копятся (квант
  0.5px), досчёт — в мёртвой зоне со свежими данными. Гистерезис маршрутов
  окном не рвётся: снапшот prev обновляется каждым не-stale прогоном, включая
  скипнутые по сигнатуре. [код]

## 5. Скип зеркальных прогонов (layoutSig)

- **AN18.** Сигнатура — МЕХАНИЧЕСКАЯ сериализация всех полей результата
  раскладки (ключи сортируются, Map/Set — по ключу; полнота «по построению» +
  тест-страж на каждое поле). Совпадение с последней применённой → прогон
  скипается: setLayout не зовётся, пересборки и ре-рендера нет; гистерезис и
  интенты при этом обновляются. Сброс сигнатуры — на смене уровня/режима.
  [тест: layoutSig.test.ts; сравнение — код]

## 6. Web Worker конвейера

- **AN19.** В воркере исполняется ВЕСЬ конвейер — тот же чистый модуль без
  собственной логики («только транспорт»); тождество результата гарантируется
  тождеством модуля и дамп-гейтом эпика. ELK — часть конвейера (динамический
  импорт внутри). [код]
- **AN20.** Обязательный хак окружения: `self.document ??= {}` ДО
  динамического импорта конвейера — elk.bundled по typeof document решает,
  библиотека он или воркер-скрипт; статический импорт хойстился бы до хака.
  Импорт воркера — только vite-канонический `?worker` (иные формы падали в
  dev). [код]
- **AN21.** Протокол: `{runId, input}` → `{runId, ok, out|error}` (Error не
  клонируется — сериализуется сообщение). Отмены в клиенте НЕТ: дисциплина
  «последний выигрывает» у вызывающего — перегнанный прогон не пишет НИЧЕГО
  (ни setLayout, ни гистерезис, ни интенты). [код]
- **AN22.** Деградации: воркер недоступен (jsdom) → прямой вызов модуля;
  воркер УПАЛ или postMessage кинул → failover: все ожидающие прогоны
  досчитываются на главном треде, воркер помечен сломанным до перезагрузки
  страницы; ok:false — законная ошибка конвейера, reject БЕЗ фолбэка. [код]
- **AN23.** На главном треде остаются: живой драг (синхронный, кадр-в-кадр),
  сборка + реконсиляция + применение, DOM-замеры, реестр мостиков,
  императивный оверлей рамок. Тесты и дамп-гейты импортируют чистый конвейер
  напрямую. [код]

## 7. laterFromFrame (rAF-якорь таймеров)

- **AN24.** Механика: requestAnimationFrame → setTimeout — отсчёт фазы от
  ПЕРВОГО ПОКАЗАННОГО КАДРА, а не от setState: тяжёлый пересчёт в окне
  отодвигает кадр, и wall-clock съедал окно до видимого старта («анимация
  пропадает, когда стрелок много»). Оба id гасятся clearTimers. [код]
- **AN25.** На laterFromFrame сидят: конец фазы 1 сворачивания и все три
  endDraw. Осознанно НЕ на нём: конец move раскрытия (отпуск уже за 2×rAF),
  фейд рамок, снятие класса на свопе — асимметрия закреплена комментариями.
  [код]

## 8. Окно жеста (drawIn после драга/undo)

- **AN26.** noteGesture зовут ровно пять мест: отпускание одиночного и
  группового драга, undo, redo и флаш клавиатурной серии сдвига (canvas.md
  CV31). Окно `GESTURE_TTL_MS = 4000` мс — страховка на случай, когда
  пересчёта не будет вовсе (дедуп коммита погасил запись). [код]
- **AN27.** Потребление: первый apply с непустым changedEdgeIds гасит флаг,
  вливает изменённые id в текущий draw-набор (union с идущей фазой) и ставит
  endDraw по объединённому набору. [тест: layoutAnimation.test.ts
  (changedEdgeIds); жизненный цикл — код]
- **AN28.** Сигнатура «геометрия изменилась»: хэндлы + АБСОЛЮТЫ обоих концов
  (сдвиг относительной позиции при том же абсолюте — не изменение) + все точки
  маршрута + центр плашки; квант 0.5px; новые/исчезнувшие/скрытые рёбра не
  участвуют. [тест: layoutAnimation.test.ts]

## 9. Каскад drawIn

- **AN29.** DRAW_CASCADE — модульная константа (не env): false → задержки не
  проставляются, одна волна. Порога «много стрелок» нет: волны возникают сами
  при > DRAW_WAVE_SIZE = 8 рёбер (первая волна — задержка 0, ≤8 рёбер ==
  одновременный старт по построению). [тест: layoutAnimation.test.ts]
- **AN30.** Порядок детерминирован: ключ — манхэттенская длина маршрута
  (короткие первыми), ребро без маршрута — нулевая длина (первая волна),
  тай-брейк — id. [тест: layoutAnimation.test.ts]
- **AN31.** Реализация волны — animationDelay на стоячем keyframes с
  fill-mode both (линия пуста до старта волны); нулевая задержка ключом не
  пишется (нормальная форма). Пока рисуется: скрыты наконечник, плашка,
  поводок; inline strokeDasharray:1 перебивает пунктир deprecated на время
  штриха. Конец фазы — по последней волне:
  `drawSpanMs(n) = 400 + (⌈n/8⌉−1)·60`. [тест: layoutAnimation.test.ts;
  рендер — код]

## 10. Мостики в окне (сверх E46)

- **AN32.** Пауза реестра — ЗАМОРОЗКА, не гашение: обновления геометрии
  глотаются (на экране последние дуги), а УДАЛЕНИЯ проходят сквозь паузу —
  иначе своп сворачивания оставлял бы полигоны мёртвых рёбер (ловится
  полигоном «финал == перезагрузка»). Снятие паузы пересобирает реестр одним
  батчем. [код]

## 11. Реконсиляция и нормальная форма масок

- **AN33.** Все маски снимаются УДАЛЕНИЕМ ключей, не записью false/пустышек
  (drawIn-пометка удаляет hidden; clearDrawIn удаляет оба ключа; unhide
  удаляет opacity и опустевший style): отгоревший анимацией объект обязан быть
  СТРУКТУРНО РАВЕН свежесобранному — иначе реконсиляция никогда не вернёт ему
  прошлый объект. [тест: layoutAnimation.test.ts, reconcileRf.test.ts]
- **AN34.** Реконсиляция идёт ДО применения по текущему (возможно
  замаскированному) стейту: замаскированный объект заменяется свежим, после
  чего apply маскирует его ЗАНОВО (AN15) — маска переживает прогон-посредник
  повторным наложением, не сохранением ссылки. [код]
- **AN41.** (2026-08-03) Пересборку RF запускает СМЕНА РАСКЛАДКИ (стейт layout)
  либо реально изменившийся параметр сборки; идентичность ЗЕРКАЛА раскладки
  триггером не является. Между отпусканием драга и готовностью конвейера
  RF-узлы держат позицию жеста, а layout — ещё дожестовый снимок: лишний
  прогон сборщика в этом промежутке применил бы СТАРЫЕ позиции (узел визуально
  откатывался бы назад и вставал на целевую только по готовности прогона —
  «откат-вперёд» страничных схем, чинено 2026-08-03). Поэтому производные
  параметры-объекты сборки стабилизируются ПО ЗНАЧЕНИЮ — relevantCounts
  (гейт лупы read-only схем, X16) считается от edges/expanded, а те
  пересоздаются на КАЖДОЕ зеркало (setGraph/setViewLayout хозяина страницы).
  [тест: levelGraph.rollback.test.tsx]

## 12. prefers-reduced-motion

- **AN35.** В движке переходов точка ЕДИНАЯ (ленивый matchMedia-гейт на каждый
  apply: интент сбрасывается, применение мгновенное; жест потребляется без
  анимации) + CSS-дубль на случай гонки класса (@media отключает транзишены и
  drawIn). [код]

## 13. Отмены

- **AN36.** Старт драга = cancel «мгновенно доиграть»: класс анимации
  снимается ДО применения состояния (транзишены объявлены только под классом —
  доигровка мгновенна); был pending фазы 1 → применяется он; иначе unmask без
  отрисовки («драгу нужна честная сцена сразу»); release досчитывает dirty в
  фоне. [код]
- **AN37.** Смена уровня/режима = reset БЕЗ доигровки: интент, жест, маски,
  draw-набор, pending, класс, пауза мостиков сбрасываются; dirty
  выбрасывается; отдельно обнуляются гистерезис и сигнатура скипа. [код]
- **AN38.** Эпоха окна гейтит async-продолжения: инкремент на каждый старт
  режиссуры и на cancel/reset; продолжение flush().then() сверяет эпоху и
  молча умирает, не трогая новое окно. Unmount: гасятся таймеры, полётный
  прогон не персистит интенты (бамп runId). [код]

## 14. Гарантия «финал == перезагрузка»

- **AN39.** Закреплена headless-полигоном dump-levels.mjs (НЕ vitest):
  структурная сигнатура всех уровней (transform узлов, path d рёбер, плашки,
  рамки; квант 0.1px) в двух состояниях — default и expanded, причём раскрытия
  кликаются ЖИВЬЁМ с полной анимацией, а каждый заход начинается с reload;
  совпадение сигнатур = «анимация не оставляет следа». [полигон, ручной запуск]
- **AN40.** Критерий тишины полигона синхронизирован с движком: LevelGraph
  публикует счётчик прогонов в полёте (`window.__archmapLayoutInflight`);
  выборки шагом 400мс, серия сбрасывается при busy, нужны 3 совпадения подряд
  (двухфазность «фолбэк-габариты → замер → пере-прогон»), кэп 16с. Эталон —
  вторым прогоном (первый прогревает засев), чеки — ролью viewer (БД не
  мутируется). [полигон]

## Известные ограничения (зафиксированы, не баги)

- Оркестровка (таймеры/маски/эпохи/gate), транспорт воркера, заморозка
  мостиков и laterFromFrame юнит-тестами не покрыты — закрепление «код +
  полигон». Юниты закрывают планировщики, сигнатуры и реконсиляцию.
- Полигон «финал == перезагрузка» — ручной (нужен поднятый dev-стек), в
  pre-commit/CI не встроен.
- Повторный жест во время идущей фазы отрисовки вливает рёбра в общий набор,
  но первый endDraw-таймер не гасится — самый ранний завершает фазу для всего
  объединённого набора (drawIn новых доигрывается досрочно мгновенным
  проявлением). Осознанно принято.
- Асимметрия якорей таймеров конца move (expand — wall-clock от отпуска за
  2×rAF, collapse — laterFromFrame) — осознанная, закреплена комментариями.
