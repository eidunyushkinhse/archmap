## 2. Что сработало (паттерны)

- **Test-first страховка перед декомпозицией.** Оркестрация LevelGraph не была
  покрыта ничем. Фаза 3а написала 58 characterization-тестов (рендер
  `LevelGraphInner` с моком `@xyflow/react`, перехват живых колбэков через
  `getCb`), и только под этой сеткой god-object разбирался безопасно. Ни одна
  декомпозиция не прошла без зелёных оркестрационных тестов.
- **Один хук — один коммит, гейт зелёный на каждом.** Pre-commit гоняет ВСЕ тесты
  (фронт+бэк) на каждом коммите. Это медленно, но гарантирует, что любая регрессия
  ловится сразу, а история бисектится по одной логической правке.
- **Делегирование фаз автономным субагентам с детальным брифом.** Каждая фаза —
  отдельный агент с полным контекстом (конвенции, команды гейта, правила коммитов,
  скоуп файлов, критерии готовности) и требованием краткого отчёта. Для фазы 3
  сначала делалась read-only разведка (структурная карта компонента: пропсы,
  useEffect/useCallback/useRef по именам и строкам, границы выноса) — она легла в
  бриф декомпозиции и сэкономила агенту повторное открытие 1600+ строк.
- **Последовательность правок кода (без параллельных коммитов).** Pre-commit
  валидирует ВСЁ дерево, поэтому два агента, правящие разные стеки одновременно,
  могут обрушить коммит друг друга (один оставил свой стек временно сломанным —
  хук другого провалился). Правки кода шли строго по одной фазе; параллельно
  допускалась только read-only разведка.
- **QA-файл как артефакт.** `QA-REFACTOR.md` вёлся по ходу: сценарии ручного
  прогона на каждую фазу + журнал коммитов + «тонкие места», где тесты тонкие и
  нужен ручной смоук. Пользователь получил единый чек-лист, а не разрозненные
  заметки по коммитам.
- **Честные решения по скоупу вместо натягивания цифер.** Где таргет достигался
  только кривой абстракцией — фиксировалось осознанное отклонение с обоснованием
  (см. §3 про <800 строк и `useLevelLayoutPipeline`).

## 3. Сюрпризы и ошибочные допущения плана

План (аудит) строился на предположениях; исполнение часть опровергло. Фиксируем,
чтобы не повторять:

- **«Каждый вынесенный хук покрыт тестами фазы 2» — НЕ подтвердилось.** Фаза 2
  физически не смогла покрыть оркестрацию LevelGraph (жёсткая связка с
  `@xyflow/react` — нужен огромный хрупкий мок; `MapEditorPage.test` мокает
  LevelGraph целиком). Потребовалась отдельная фаза 3а (characterization-тесты).
  **Урок:** тестовое покрытие god-компонента — самостоятельная работа, её нельзя
  «приписать» другой фазе авансом.
- **`useLevelRemoteMirror` не имеет собственного тела.** План наметил его как
  отдельный хук, но `onLayoutChanged`/`gestureActiveRef`/`viewMeta` живут внутри
  персиста и драга — выносить нечего. **Урок:** границы хуков сверять с кодом, а
  не со схемой «на глаз».
- **`gestureActiveRef` — гейт ПОЛЛИНГА, а не зеркала.** Бриф предполагал «паузу
  зеркала на время жеста» — в коде этого нет (ref взводится для `useRemoteSync`
  родителя). **Урок:** не закладывать поведение, прочитанное из названия.
- **Конвейер раскладки атомарен — вынести нельзя.** Эффект-сборщик ОБЯЗАН быть
  объявлен ДО data→computeNow эффекта (инвариант «тихого окна» анимации);
  `computeNow` от сборщика неотделим. Полный вынос = 22 параметра (за порогом),
  частичный — молча ломает батчинг анимации (тесты НЕ ловят: `useLayoutAnimation`
  замокан). **Урок:** не всякая «ответственность» выносится в хук; атомарные ядра
  с инвариантами порядка эффектов остаются в компоненте.
- **<800 строк LevelGraph недостижимо чистой декомпозицией хуков.** Неснижаемый
  остаток ~950–1050: JSX-рендер (~260, не выносится), атомарный конвейер (~150),
  cbRef-оркестрация, драг-склейка. Дальше — только фрагментация JSX на
  подкомпоненты (риск для канваса ради цифры). **Осознанное отклонение:**
  остановились на 1055. Пропсы <20 — достигнуты (19).
- **TS strict оказался «бесплатным» (0 ошибок).** План ждал «лавину
  strictNullChecks на 31k строк». Код уже писался по правилу «без any, типизировать
  явно» — компилятор лишь догнал дисциплину. **Урок:** строгость типов дёшева, если
  дисциплина есть; дорогой сценарий — включать strict в коде с `any`/нетипизированными
  границами.
- **eslint strict = в основном `no-non-null-assertion` в ТЕСТАХ.** Из 289 ошибок
  ~230 — идиоматичные `result.x[0]!` в characterization-тестах. Решение: для тестов
  правило отключено (конвенция), в продакшне ~50–60 устранены по-настоящему.
- **mypy потребовал pydantic-плагин** ровно в момент, когда поля `Settings` стали
  обязательными (fail-fast): без плагина mypy требует аргументы `Settings()`, не
  зная про заполнение из окружения.

## 4. Playbook декомпозиции god-компонента (проверенный)

1. **Разведка (read-only):** карта компонента — все пропсы, каждый
   useEffect/useCallback/useRef/useMemo по именам+строкам, зоны ответственности и
   их привязка к хукам, кандидаты границ выноса и МЕЖХУКОВЫЕ зависимости (общие
   ref/state — главный риск).
2. **Страховка:** characterization-тесты на оркестрацию (рендер внутреннего
   компонента с моком тяжёлых зависимостей, перехват колбэков). Фиксируют
   контракты «какой колбэк с какими аргументами при каком условии».
3. **Порядок выноса:** сначала ИЗОЛИРОВАННЫЕ хуки (только читают — locate,
   selection), затем ЦЕНТРАЛЬНЫЕ узлы (persistence: `commitLayout` — точка
   схождения драга/expand/конвейера), затем ЗАВИСИМЫЕ (drill зовёт `commitLayout`).
   Один хук — один коммит.
4. **Инварианты:** сохранить latest-ref паттерн и порядок эффектов (сборщик RF
   читает свежий `cbRef`); новые хуки НЕ мокаются в тестах (исполняются по-настоящему)
   — иначе тесты ничего не ловят.
5. **Пропсы:** группировать в НЕСКОЛЬКО связных доменных бандлов (persistence, mode,
   drill, edgeCallbacks, delete, drop, undo), а не в много одиночных объектов.
   Бандлы в точках вызова — через `useMemo` ( ссылочная стабильность, без лишних
   ре-рендеров канваса). Общие типы (LocateRequest/ViewMetaState) — в общий модуль,
   чтобы убрать type-only циклы компонент↔хуки.
6. **Честный стоп:** если вынос требует 20+ параметров или рвёт инвариант — не
   форсируем; фиксируем чистый пол и обоснование.

## 5. Процессные уроки

- **Коммитить и пушить часто.** Фоновый агент встал на ~7.5 ч при обрыве сети
  (LLM-вызовы не проходили); спасло то, что работа коммитилась и пушилась в origin
  по фазам — прогресс не потерялся. Для долгих автономных сессий push по фазам —
  обязательная гигиена.
- **Брифы субагентам — самодостаточные.** Агент стартует без истории диалога: в
  промпт кладём конвенции (язык коммитов/комментариев, команды гейта, скоуп,
  «не трогать»-список файлов), структурную карту и критерии готовности. Требование
  краткого отчёта (без простыней кода) бережёт контекст координатора.
- **Read-only разведку можно параллелить с кодом; правки кода — нет** (см. §2 про
  pre-commit на всё дерево).
- **mypy/strict/линтеры в гейте** (pre-commit + CI-зеркало) — то, что машина может
  проверить, держим в машине; `--no-verify` не используется.
