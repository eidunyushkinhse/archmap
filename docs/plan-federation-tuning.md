## Ф5: матрица прогонов и критерии

Протокол прежний: Haiku headless, оркестраторные промпты с ручек, кнопочные
тексты замечаний, ≤2 круга на файл.

**Изолированные (регрессия — НЕ ХУЖЕ прежних):** Zabbix 7, Zulip, Sentry —
импортный путь, чекбокс федерации ВЫКЛ (промпт отличается от прежнего только
П13-строками и П5-перечнями в замечаниях).
Критерии: (а) превью финала — 0 ошибок, предупреждений не больше, чем на
соответствующем прежнем раунде, за ≤2 круга; (б) продукт НЕ обёрнут лишним
контейнером-самодублем (регрессия П1); (в) число кругов до чистого превью не
выросло; (г) выборочная семантика — нет НОВЫХ классов лжи против прежних
отчётов (Zabbix: alerter/Symfony-классы; Zulip: ES/tornado; Sentry:
Kafka/taskbroker — по qa-докам).

**Федерация (должна УЛУЧШИТЬСЯ):** Zabbix + Grafana + плагин Зобнина, чекбокс
ВКЛ, тот же состав репозиториев.
Критерии против docs/qa-multirepo-federation.md: (а) продукты-контейнеры и
склейка федерации с ПЕРВОГО захода — ноль перегонов с hints и ноль дожимов
(было: 2 перегона + 1 дожим); (б) «grafana» един (П3), external у Grafana
честный (П2); (в) схемная секция ≤ 5 строк только истинно межфайловых (было
10–12, включая уехавшие сироты и контейнеры); (г) сумма пофайловых кругов ≤ 3
(было 4 + починка YAML); (д) алертов на создании < 23 при том же усилии;
(е) счёт ручных действий пользователя строго меньше прежнего раунда (перегоны,
дожимы, ручные правки — перечислить в отчёте).

   связи) — переписывать с комментарием, тест-зеркало суммы корзин должно
   остаться зелёным.
4. П6: пути результата согласовать во ВСЕХ местах (обёртка: шаги 1/2/4/5/6;
